# swos-api

An independent, device-agnostic Python API for managing MikroTik SwOS devices.

The project will provide:

- `swos-core`: the public Python API and device plugin interface
- `swos-cli`: a command-line client built exclusively on `swos-core`
- device support packages such as `swos-device-css106`
- a future Ansible integration built on the same API

The project is in its initial development phase.
